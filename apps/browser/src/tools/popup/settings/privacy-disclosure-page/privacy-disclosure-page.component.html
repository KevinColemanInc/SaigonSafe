This page explains the browser access and network activity used by the Saigon Safe extension. It is a product disclosure summary for the extension itself.

What the extension can access

  • The extension can run on HTTP and HTTPS pages so it can detect login forms, offer autofill, save logins, and support passkeys across websites.
  • The extension reads page structure and URLs needed for autofill, passkey flows, phishing checks, and vault matching. It is not intended to collect the full contents of every page.

Local-only features

  • Vault data, autofill decisions, and most page analysis happen inside the extension on your device.
  • Clipboard actions are used for copy and paste features. In Manifest V3 builds, clipboard reads and writes can use an offscreen document provided by the browser.
  • Biometric unlock uses native messaging to communicate with the local desktop app on your device only after you enable the feature and grant that permission.

Network activity

  • The extension connects to your configured Saigon Safe server or web vault for account, sync, and vault operations.
  • The phishing blocker downloads remote blocklist data used to identify known phishing sites. Those downloads are separate from your normal vault sync traffic.
  • The browser extension does not upload phishing warning, bypass, or exit events as part of the phishing protection flow.

User controls

  • You can review and change extension settings for autofill, clipboard timeout, browser privacy integration, phishing protection, and biometrics.
  • Browser-managed permissions such as privacy settings access and biometric native messaging may require an additional prompt or browser-level opt-in.
  • If you do not want the extension to operate on a site, use the blocked or excluded domain settings where available.

Source and updates

Current source, release notes, and implementation details are published in the Saigon Safe project repository.
