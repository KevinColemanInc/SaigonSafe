Privacy Policy for the Saigon Safe Browser Extension

This policy applies to the Saigon Safe browser extension distributed for Chromium-based browsers and Firefox. It describes what the extension can access, what data it may process, what network activity it performs, and what controls the user has.

Last updated: May 20, 2026
Product: Saigon Safe Browser Extension
Scope: Chrome and Firefox extension builds

Summary

The extension exists to help users store, sync, and autofill credentials and other vault items on websites they choose to use. To do that, it needs broad website access, local encrypted storage, clipboard integration, and limited background browser APIs.

Policy intent

This page is intended to be the public privacy policy URL for store listings and user review. It should be kept aligned with the current extension behavior and permissions.

1. What the extension can access

  • The extension can run on HTTP and HTTPS pages so it can detect login forms, support autofill, save new logins, and assist with passkey flows across websites.
  • The extension reads page structure, URLs, and form-related context needed for vault matching, autofill decisions, phishing checks, and related security behavior.
  • The extension does not request access to local file:// pages.

2. Local data handling

  • Vault data, encryption keys, autofill decisions, and most page analysis are intended to be handled locally inside the extension or against the user’s configured Saigon Safe service.
  • The extension uses browser storage and related extension storage APIs to preserve user state and security settings.
  • Clipboard read and write features are used only to support user-facing copy and paste actions such as copying usernames, passwords, TOTP values, or generated content.

3. Network activity

  • The extension connects to the user’s configured Saigon Safe server or web vault for account authentication, sync, vault operations, and related product functionality.
  • The extension may download phishing blocklist data used to identify known phishing sites. These downloads are separate from ordinary vault sync traffic.
  • The current browser phishing-protection flow does not upload phishing warning, bypass, or exit events.

4. Optional and user-controlled features

  • Privacy-settings integration is requested only when the user chooses a feature that needs it.
  • Biometric unlock uses native messaging to communicate with a local desktop app only after the user enables biometrics and grants that permission.
  • Users can disable or avoid specific features such as phishing protection, browser privacy integration, or biometric unlock through extension settings.

5. Browser permissions in use

Depending on browser target and manifest version, the extension may request permissions needed for autofill, clipboard operations, browser action behavior, notifications, idle-based lock handling, web navigation checks, authentication challenge handling, and optional biometric/native-messaging flows.

Permission prompts are expected to reflect the extension’s current feature set. The project aims to keep optional features behind optional permissions where practical.

6. User controls

  • Users can review and change settings inside the extension at any time.
  • Users can block or exclude sites from extension operation where supported by the product.
  • Users can remove the extension at any time through the browser’s extension manager.

7. Scope and third parties

This policy covers the Saigon Safe browser extension itself. It does not replace any separate privacy terms that may apply to a user’s configured server, web vault, or related self-hosted infrastructure.

If the extension is pointed at a self-hosted or third-party service, the operator of that service may control server-side logging, retention, and account handling outside the extension code.

8. Contact and source

Questions, issue reports, and source review can be directed to the public repository: github.com/kevincolemaninc/saigonsafe.

If the extension behavior changes in a way that materially affects permissions, network traffic, or personal data handling, this page should be updated before release.
